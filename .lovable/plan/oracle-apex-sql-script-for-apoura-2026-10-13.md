# Oracle APEX SQL script for Apoura

Create a single downloadable file, `apoura_oracle_apex.sql`, saved to Files. It creates every table the app needs and fills it with all the current data. You can run it in APEX SQL Workshop > SQL Scripts. The app itself does not change.

## Landing page sections covered
Header and menu, hero with search bar, 13 category tiles, featured organisers, featured vendors, how it works, business steps, business banner, FAQs, footer. Every section's data is in a table above.

## Rules built into the script
- Booking totals: price x units; deposit = 20% rounded; balance = total - deposit (calculated columns).
- Status limited to: confirmed, quote requested, quoted, cancelled, completed.
- Provider kind limited to VENDOR or ORGANISER. Only vendors are linked to categories.
- Ratings between 0 and 5, prices 0 or more.
- Primary keys use identity columns. Foreign keys and indexes are added for search by category, city and price.

## Extras in the same file
- A view `APR_V_VENDOR_SEARCH` that joins providers, categories and sub-services for APEX reports and search pages.
- Notes at the top on running order, plus a cleanup section (commented out) to drop the tables.

## Notes
- Vendor names, prices and ratings are the sample data already in the app. Replace them with your real vendors.
- Image URLs are the current hosted photo links.
- APEX handles sign-in itself, so APR_USERS only stores profile and role information, with no passwords.

## Technical details
- Oracle 19c+ syntax: `GENERATED BY DEFAULT AS IDENTITY`, `CHECK` constraints, virtual columns for deposit and balance, `CLOB` for notes, `TIMESTAMP DEFAULT SYSTIMESTAMP`.
- Seed data comes straight from the app's category, listing and FAQ lists so nothing is retyped by hand. Inserts are plain statements followed by `COMMIT`.
